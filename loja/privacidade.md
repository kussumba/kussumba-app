# Política de privacidade da KUSSUMBA

*Última actualização: 29 de Setembro de 2026*

A KUSSUMBA é uma aplicação para planear e registar as compras de casa. Esta política explica o que acontece aos dados que nela escreves.

## Que dados a aplicação guarda

A KUSSUMBA guarda apenas o que escreves nela: o plafond de cada mês, a lista de compras, os produtos que criares, as lojas onde compraste e os preços que pagaste. Não pede nome, número de telefone, email, localização, fotografias nem contactos.

## Onde ficam os dados

Os dados ficam só no teu telefone, dentro da aplicação. A KUSSUMBA não usa a internet: não envia dados para nenhum servidor, não tem publicidade nem estatísticas de uso e não partilha nada com ninguém.

## Cópia de segurança

Quando escolhes "Guardar cópia", a aplicação cria um ficheiro com os teus dados e guarda-o no sítio que indicares (por exemplo, a pasta de transferências do telefone ou o Google Drive). Esse ficheiro fica sob o teu controlo; a KUSSUMBA não o envia para lado nenhum. Ao repor uma cópia, a aplicação lê apenas o ficheiro que escolheres.

## Apagar os dados

Para apagar todos os dados, basta desinstalar a aplicação ou limpar os dados dela nas definições do telefone. As cópias de segurança que guardaste fora da aplicação apagam-se como qualquer outro ficheiro.

## Crianças

A KUSSUMBA destina-se a adultos que fazem as compras de casa e não recolhe dados de ninguém, incluindo de crianças.

## Alterações e contacto

Se esta política mudar, a versão nova é publicada neste mesmo endereço, com a data de actualização. Para perguntas: <https://github.com/kussumba/kussumba-app/issues>.
